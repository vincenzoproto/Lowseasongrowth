## How hoteliers can use the two practitioner tools

**Weak-Date Diagnosis** is intended to structure the question *why is this stay window weak?* before changing price. It compares booking position and pickup at matched horizons, records alternative explanations, and turns the evidence into one bounded test.

**Low-Season Offer Economics** is intended to test whether an offer can create incremental contribution after selling costs, variable costs, included benefits, campaign spend and plausible cannibalisation. It is a decision worksheet, not a promise of uplift.

Used together, the workflow is: **diagnose the weak date → define a bounded intervention → test the economics → run the test → compare actual versus assumed inputs → document the learning.**

## Citation and interpretation

- Official source figures remain attributed to the original source institution.
- LSG calculations are explicitly labelled as LSG descriptive calculations.
- National and regional tourism statistics should not be treated as individual-hotel performance benchmarks.
- Research Notes are descriptive analyses, not forecasts.
- Practitioner-tool numerical examples are synthetic and should not be presented as hotel results, market benchmarks or case studies.
- Cite the DOI record for a stable reference to each archived publication.
