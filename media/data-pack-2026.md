# Low Season Growth Media Data Pack 2026

Eight reusable charts supporting Low Season Growth Research Notes 01–04.

Official media page: https://lowseasongrowth.com/pages/media-data-pack-2026

## Reuse rules

- Attribute the underlying source shown for each chart.
- Attribute **Low Season Growth** when using an LSG-derived metric or chart.
- Do not describe an LSG-derived metric as an official indicator from the source institution.
- Do not compare Europe, Caribbean and Japan charts as if they use the same metric.
- Use the canonical Research Note for methodology and limitations.
