# Low Season Growth

Low Season Growth (LSG) is a hospitality strategy project focused on helping independent hotels, B&Bs and guesthouses improve low-season positioning, direct-booking opportunities and seasonal commercial planning.

Website: https://lowseasongrowth.com

## Public repository scope

This repository is intentionally limited to public-facing material:

- research and citation metadata
- press and media assets
- brand assets intended for public use
- machine-readable organisation metadata
- public AI/knowledge documentation

Operational CRM data, prospect lists, customer data, sales-partner records, private procedures, Shopify backups and internal workflows are not stored in this public repository.
