# Low Season Growth

Experimental Shopify storefront for **lowseasongrowth.com**.

## Purpose
This repository is intentionally separate from the main hospitality/creator projects. It is used only to test and improve the Low Season Growth Shopify theme.

## Safe workflow
1. Build and test theme changes in this repository.
2. Connect only a Shopify **draft/unpublished theme** to the development branch.
3. Preview on mobile and desktop.
4. Publish manually in Shopify only after checkout, payments, legal pages and navigation are verified.

## What belongs here
- Shopify Liquid theme code
- CSS / JavaScript
- Theme assets
- Sections, snippets and templates
- UI/UX experiments

## What must never be committed
- Passwords or passkeys
- Shopify API tokens / secrets
- Bank or payout data
- Customer personal data
- Private keys

## Current priorities
- Premium, simple hospitality positioning
- Strong mobile hero and CTA hierarchy
- Clear 3-package comparison
- Fast navigation and lightweight interactions
- FAQ accordion and trust elements
- Consistent Low Season Growth branding
- Accessibility and performance
