# Low Season Growth

Experimental Shopify storefront for **lowseasongrowth.com**.

## Purpose
This repository is intentionally separate from the main hospitality/creator projects. It is used only to test and improve the Low Season Growth Shopify theme.

## Safe workflow
1. Build and test theme changes on the `theme-v2` branch.
2. Keep Shopify changes on the **Low Season Growth - Draft** theme until QA is complete.
3. Preview on mobile and desktop.
4. Publish manually in Shopify only after checkout, payments, legal pages and navigation are verified.

## Current theme
The `theme-v2` branch mirrors the custom Shopify draft homepage:
- `sections/low-season-growth-home.liquid`
- `templates/index.json`

Current design direction: premium, simple hospitality consulting; ivory / forest palette; property-specific positioning; lightweight animation; distinct package imagery; mobile sticky CTA; accessible FAQ accordion.

## What belongs here
- Shopify Liquid theme code

## What must never be committed
- Passwords or passkeys
- Shopify API tokens / secrets
- Bank or payout data
- Customer personal data
- Private keys
